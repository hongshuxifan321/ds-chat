# DS Chat 文档索引

整理时间：2026-11-17

## 这是什么

一个**自带 API Key 的 DeepSeek 对话客户端**：纯静态网页，可安装成桌面/手机 App，Key、会话和附件全部存在本地浏览器里。
不是 DeepSeek 官方产品，与深度求索无关。

## 图标

源文件在 `public/icons/`：512 / 512-maskable / 192 / apple-touch / favicon-32 共 5 个。
由 `scripts/make_icons.py` 生成，改参数后重跑即可；构建时会被复制进 `dist/icons/`。

## 本地预览

构建后把 `dist/` 内容拷进 `preview/`，双击 `preview/启动预览.cmd`。
浏览器自动打开 `http://127.0.0.1:8090/`，终端会同时打印局域网地址，同一 Wi-Fi 下手机可直接访问（HTTP 下不能安装为 PWA，只能当网页用）。
首次使用在**设置**里填自己的 DeepSeek API Key。关闭命令行窗口即停止服务。

| `public/sw.js` | 静态资源缓存策略，API 请求不拦截 |
| `public/icons/*` | 程序生成的 DS 字母图标 |
| `src/services/links.ts` | 开放平台外链常量（与对话协议无关） |
| `src/components/sider/BalanceCard*` | 新增侧边栏底部余额卡：余额、赠金（仅非 0 时显示）、去充值；未填 Key 不渲染；60 秒内存缓存，点击刷新，每轮回答结束补刷，金额不落盘 |
| `src/services/api/balance.ts` | 余额查询接口（`/user/balance`），与对话协议无关 |
| `src/components/settings/SettingsDialog.tsx` | 三步引导 + 两个教程弹窗 + 历史导入（上传 ZIP / 选文件夹、三段式进度、失败原因分列） |
| `src/services/chat/sessionGroups.ts` + `SessionItem*` | 会话置顶：置顶单独成组排在最前，菜单可置顶/取消；不改 `updatedAt`；归档的 `pinned` 导入导出都保留 |
| `src/services/chat/history/*` | 导入容错：坏会话跳过不整包失败、消息树自动修复、支持系统已解压的文件夹、进度按会话/附件/提交三段回报、替换时边复制边删暂存；`pinned` 导入导出都保留 |
| `src/i18n/*.ts` | 品牌名 DS Chat；引导、教程、导入、余额、置顶相关文案 |
| `src/utils/*`（输入相关） | 触屏设备回车改为换行，不再直接发送 |
| `src/services/api/*`（解析） | 拿不到流式响应体时整段解析、响应头只当提示——只修健壮性，不改请求字段 |
| `README.md` / `README.zh-CN.md` | 非官方声明、定位、与上游差别 |

协议层（`system`、`latest_reminder`、`tools`、历史消息构造）**一个字没动**。
