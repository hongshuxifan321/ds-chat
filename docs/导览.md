# DS Chat 文档索引

整理时间：2026-11-17

## 这是什么

一个**自带 API Key 的 DeepSeek 对话客户端**：纯静态网页，可安装成桌面/手机 App，Key、会话和附件全部存在本地浏览器里。
不是 DeepSeek 官方产品，与深度求索无关。

## 图标

源文件在 `public/icons/`：512 / 512-maskable / 192 / apple-touch / favicon-32 共 5 个。
由 `scripts/make_icons.py` 生成，改参数后重跑即可；构建时会被复制进 `dist/icons/`。

## 本地预览

构建后把 `dist/` 内容拷进 `preview/`，双击 `preview/启动预览.cmd`。
浏览器自动打开 `http://127.0.0.1:8090/`，终端会同时打印局域网地址，同一 Wi-Fi 下手机可直接访问（HTTP 下不能安装为 PWA，只能当网页用）。
首次使用在**设置**里填自己的 DeepSeek API Key。关闭命令行窗口即停止服务。

| `src/services/chat/db.ts`（原件存储） + `history/importArchive.ts` | 手机浏览器写不进 Blob 的兜底：探测失败或写入报 `Error preparing Blob/File data` 时，图片改存 base64、读取时透明还原（`loadFile` 仍返回 Blob，上层不用改）；导入逐张容错，写不进的只跳过该图并报张数；导入前用 `estimate()` 预检剩余额度，不够就直说「空间不足」 |
