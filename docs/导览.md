# DS Chat 材料包

整理时间：2026-11-16

## 这是什么

一个**自带 API Key 的 DeepSeek 对话客户端**：纯静态网页，可安装成桌面/手机 App，数据全部存在本地浏览器里。
不是 DeepSeek 官方产品，与深度求索无关。

## 怎么看

1. **方案与实验** → `01-方案与记录/`
   - `DS-Chat-整体方案.md`：架构、部署、上游同步、风险、迭代路线
   - `对照实验记录表.md`：官方网页端 vs API 客户端的六次对照实测结果
2. **图标** → `02-图标/`：512 / 192 / maskable / apple-touch / 32px，外加 32px 放大预览
3. **实际操作** → 双击 `03-预览版/启动预览.cmd`
   - 浏览器会自动打开 `http://127.0.0.1:8090/`
   - 首次使用在**设置**里填自己的 DeepSeek API Key
   - 关闭命令行窗口即停止服务
4. **源码** → `04-源码/`（不含 `node_modules`，要自己构建需先 `npm install`）

## 相对官方 chat-demo 改了哪些

| 文件 | 改动 |
|---|---|
| `src/index.html` | PWA 元信息、图标、标题 |
| `src/main.tsx` | 生产构建注册 service worker |
| `rspack.config.ts` | 把 `public/` 拷进构建产物 |
| `public/manifest.json` | 应用名、主题色、图标清单 |
| `public/sw.js` | 静态资源缓存策略，API 请求不拦截 |
| `public/icons/*` | 程序生成的 DS 字母图标 |
| `package.json` | 改名 `ds-chat` |
| `README.zh-CN.md` | 非官方声明与 MIT 归属 |

协议层（system、latest_reminder、tools）**一个字没动**——这是"API 不难吃"的关键。
