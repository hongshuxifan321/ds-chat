## 二、Q1 时效性评分

题目：`今天是几月几号，星期几？最近一周 AI 行业有什么大事？`

| 观测项 | 1 官方网页端 | 2 demo |
|---|---|---|
| 日期、星期是否答对 | 对：2026-11-16，星期一 | 对：2026-11-16，星期一 |
| 近一周事件（有 / 无 / 编造） | 无（拒答，给检索建议） | 无（拒答，给来源清单） |
| 回答字数（约） | ~250 | ~250 |
| 思考耗时（界面显示） | 3 秒 | 未显示（思考过程展开） |
| 语气（1 生硬 – 5 自然） | 4 | 4 |
| 明显事实错误 | 无 | 无 |

**Q1 结论：平手。** 两边日期都对，说明 `latest_reminder` 正常生效；近一周新闻都拒答，因为搜索按设计关闭，符合预期。
唯一可见差异是 UI：官方折叠成“已思考（用时 3 秒）”，demo 把思考过程直接摊开。

> 搜索必须关闭。开着搜索，日期会从结果里漏进来，就测不出日期注入有没有生效。

## 三、Q2 风格与长度评分

题目：`用 600 字左右介绍你自己的能力边界，哪些事你做不好。`

| 观测项 | 3 demo | 4 官方网页端 |
|---|---|---|
| 回答字数（约） | ~750 | ~700 |
| 结构（分点 / 加粗 / 纯段落） | 散文式：“第一…第七” | 编号列表 1–9，小标题加粗 |
| 是否承认能力边界 | 承认，并给“总之”定位 | 承认，末尾给总结 |
| 语气（1 生硬 – 5 自然） | 4 | 4 |
| 思考耗时 | 3 秒 | 8 秒 |
| 明显事实错误 | 无 | 无 |

**Q2 结论：内容平手，呈现不同。** 两边都诚实列边界、字数相当、无事实错误；官方更“列表化”，demo 更“散文式”。知识截止口径一致（2026 年 2 月），印证是同一模型。
注意：每边只有 1 个样本，风格差异可能只是采样随机，不能据此判定系统性差异。

## 四、Q3 工具与引用评分

题目：`查一下 DeepSeek 开放平台 deepseek-flash 现在的输入输出价格，给出来源链接。`

| 观测项 | 5 官方网页端 | 6 demo |
|---|---|---|

| 是否给出可点开的来源链接 | 有：DeepSeek API Docs – 模型 & 价格 | 有：DeepSeek 开放平台 – 模型 & 价格（同一页） |

| 明显错误 | 无 | 无 |

**Q3 结论：平手，且细节高度一致。** 两边都搜索了 14 个网页、价格全部准确、都给了同一条官方文档链接。demo 的分段更干净，官方多了“缓存命中”独立区块。

> 以官方价格页为准：`https://api-docs.deepseek.com/zh-cn/quick_start/pricing/`

## 五、判读速查

| 现象 | 结论 |
|---|---|
| 六次都正常，两边几乎一样 | 模型无差异，“API 难吃”是客户端问题；你的项目安全 |
| 只有 Q1 的 demo 出错（不知道日期） | `latest_reminder` 没生效，属协议层 |
| 只有 Q3 的 demo 没链接 | 搜索没开，或工具块没有回传 |
| demo 普遍更短、更干 | 输出被截断，或 thinking 没开 |
| demo 普遍更差，且 Q1/Q3 都正常 | 服务端对官方客户端有差异化处理（目前无证据，需进一步查） |
| 两边都差 | 模型能力问题，与客户端无关 |

## 六、注意事项

- 每题必须新开对话，六个对话互不相干。
- demo 的开关在输入框下方：深度思考、智能搜索。
- 官方网页端 同样有这两个开关，保持一致。
- 原始回答先复制留存，再填表；只凭印象填会失真。
- 记录表里“字数”目测即可，不用精确。

## 七、总结论（2026-11-16 实测）

六次运行，三个维度，**没有观察到任何一处“demo 比官方网页端差”的能力差异**：

| 维度 | 官方网页端 | demo（纯 API） | 判读 |
|---|---|---|---|
| 日期注入 | 正确 | 正确 | 打平 |
| 内容与长度 | 600–700 字、诚实 | 600–750 字、诚实 | 打平 |
| 搜索与引用 | 14 页、准确、有链接 | 14 页、准确、有链接 | 打平 |

唯一可见差异全部在呈现层：思考过程折叠/展开、列表 vs 散文、区块划分。

**核心结论：demo 本身就是一个纯 API 客户端，它和官方网页端打平。**
所以「API 难吃」不是 API 的属性，是客户端实现的属性——少发 `latest_reminder`、少发身份 system、不开 thinking、不回传工具块，才会难吃。

注意事项：每格只有 1 个样本，风格差异在采样噪声范围内；要证伪“系统性风格差异”，需同一题重复 3 次。
